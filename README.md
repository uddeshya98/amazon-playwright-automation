# Amazon Playwright Automation Project

## Overview
This project contains an automated end-to-end test suite for Amazon.in using Playwright. The tests cover searching for products, adding them to the cart, and printing their prices.

### Test Cases Implemented:
1. **Test Case 1**: Navigate to Amazon.in, search for "iPhone", select a product, add to cart, and print the price in the console.
2. **Test Case 2**: Navigate to Amazon.in, search for "Samsung Galaxy", select a product, add to cart, and print the price in the console.

## Setup Instructions

### Prerequisites
- Node.js (v14 or above)
- A LambdaTest account for cloud execution

### Installation
1. Clone the repository and navigate into the project directory.
2. Install the necessary dependencies:
```bash
npm install
```
3. Ensure Playwright browsers are installed:
```bash
npx playwright install
```

### Environment Configuration
1. Create a `.env` file in the root directory.
2. Add your LambdaTest credentials:
```env
LT_USERNAME=your_username
LT_ACCESS_KEY=your_access_key
```

## Running Tests

### Run locally
To run the tests on your local machine:
```bash
npx playwright test --project=local
```

### Run on LambdaTest Cloud
To execute the tests remotely on the LambdaTest Grid:
```bash
npx playwright test --project=lambdatest
```

### Parallel Execution
The framework is configured to run tests in parallel. In `playwright.config.js`:
- `fullyParallel: true`
- `workers: 2` (or more)

This ensures Test Case 1 and Test Case 2 execute concurrently, speeding up the overall test suite time.
